## Verified behavior

- **Common valid sites:** `reconstruction_diagnostics.py:29–40` intersects proposed/reference keys and excludes either side's `None` before forming deltas and group totals. `analyze_expansion_reconstruction.py:210–216` uses that same mask for token/bullet changes and reports missing or invalid pairs. This supports a paired comparison conditional on that mask; each method's separate absolute mean need not use the same population.
- **Whole related-group bootstrap:** group totals and retained-site counts are resampled together, then divided, preserving equal activation-site weights. An independent enumeration used one two-site group with changes .2/.4 and one one-site group with change0. The four possible draws give means .3/.2/.2/0; the observed mean is .2, rather than the incorrect equally weighted group mean .15. The implementation matched this enumeration and the intended common mask. These are pointwise percentile intervals on observed related groups, not simultaneous or causal guarantees.
- **Zero is distinct from unavailable:** the actual journals contain **95,926** cached exact fits, **36,702** explicit-empty zero fits and **647** unavailable `AR_empty_after_cleanup` fits. An unavailable atom invalidates that readout's comparable fit rather than being silently dropped. No journal `None` was converted to zero. `saved_fit` rejects nonfinite/bool values, incompatible solvers, differing recorded atom IDs, inappropriate fit scope and nonzero fits for empty output.
- **Comparable emitted atoms:** replay reconstructs selected output verbatim from the original N32 sample pool, checks selected bullet/token counts, uses retained source phrase IDs, and applies the same cleaned first32-token cache keys and frozen tag heads. Saved source fits are accepted only when full emitted text hash and output counts match the selected output. Raw unmodified N1 is explicitly unavailable, rather than represented by a capped or parsed fit. Exact and released80 fits are not mixed.
- **Normalizations:** both targets and predictions are centered and whitened with the layer-specific frozen pooled artifact and ridge .1. Phrase directions are divided by norm+1e-9; the target keeps its whitened magnitude. The NNLS solver uses float64 SciPy after the same float32 transformations, with no final FVE clipping. All19,435 targets differ from the corresponding whitener mean; the minimum squared raw-centered target norm across layers was267.615. With the positive-ridge invertible whitener, the exact-zero-target corner is absent from these data. This check does not claim to have independently recomputed every selected NNLS fit.
- **Boundary warnings:** the current absolute-mean helper exposes zero-bootstrap-variation and all-zero/all-one warnings. A deliberately all-zero two-group example produced [0,0] with both warnings. Paired intervals also warn about zero bootstrap variation; no-common-site intervals are undefined. The complete/partial row counts and missing/unavailable counts must remain visible in delivery.

## Actionable boundary hardening and reporting limits

1. **Future editor-pruning intake needs stronger authority checks.** `analyze_expansion_reconstruction.py:159–167` pins generic pruning spec/status/journal files and checks fit identity/text, but does not compare journal rows to the pruning spec, validate the spec's frozen objective/vector authority, or require terminal journal SHA/expected-grid coverage. A matching text with an incompatible scalar fit could therefore pass this specific intake. No new editor-pruning family was available in this snapshot, so this is a prospective gap, not an observed failed row. At the next offline boundary, validate the producer's actual terminal/spec/row contract before retaining these fits; do not mutate the running GPU service.
2. **Replay resume provenance must preserve previously used sources.** `expanded_reconstruction_replay.py:101` processes only unfinished cells, while its terminal source set is assembled from sources touched in the current invocation at174–178. A resumed run can omit vector files, whiteners or stage sample/selector sources used only by previously committed rows. Persist and validate cumulative source pins across resume, or rederive them from all committed rows before terminal publication. The reviewed four workers completed uninterrupted, with full terminal source inventories; this is not an observed mismatch in their output. Likewise pin the helper modules/constants and tokenizer configuration used by replay at a future source boundary rather than treating an implementation subset as the entire runtime.
3. **Valid-mask conditioning matters in the final figures.** The647 genuinely unavailable fits make some semantic-condition means partial. Display scored/intended sites and common-pair counts beside reconstruction summaries. A quality rate on its full native task denominator and FVE on valid activation sites are different summaries; an apparent absolute-mean advantage is not automatically a paired gain. Missing selection, unextracted fit, invalid cleaned atom, raw unavailable, and explicit-empty zero have different meanings.
4. **Thirty-two scored tokens are a scientific limitation.** FVE measures whitened reconstruction from the first32 cleaned tokens of each emitted atom, not truth or completeness of its entire prose. Deleting a low-fit detail does not demonstrate that it was false, and adding columns can improve unpenalized NNLS without improving behavioral quality. Retain the existing B32/B128 sensitivity and phrase-prefix risk discussion in the method report. Reconstruction and native behavioral outcomes should be presented separately by method and family.
