Search existing bullets, then check what survived

Every output uses at most four intact source bullets and 256 Qwen text tokens. The original raw lens is shown separately and is exempt from this cap.

The search score asks how well the text reconstructs the current activation. Benchmark judgments ask whether the text recovers the required facts or contradicts the transcript.

Repeat bullet swaps

Start from plain pooled-32. Try replacing one bullet, fit the complete set again, and repeat while the fixed search budget permits.

What is compared?

Compare with plain pooled-32 to measure the added search. The one-bullet replacements come from the same frozen pool. A complete-response fallback is already included in the saved parent.

Repeat swaps, then prune

Remove a bullet if its refitted reconstruction contribution is at most 0.005; refit again before the next deletion.

Why also delete at random?

The matched deletion method removes exactly as many bullets from the repeated-swaps parent on each activation. It helps distinguish guided removal from the effect of shorter output.

Prune and refill

Remove weak bullets, then explore bounded additions and replacements. Keep the best validated set in which every remaining bullet contributes more than 0.005.

Why can fewer bullets be best?

This is a constrained search. A larger set with a higher overall reconstruction score can still contain a weak bullet and fail the constraint. The method does not force four bullets.

Matched random deletion

Use frozen random seeds to delete the same number of bullets removed by guided pruning after repeated swaps.

Which parent is used?

Its parent is the repeated-swaps result. The earlier plain-pooling deletion comparator is retained separately, with the plain pooled result as its parent.

Interpret the task endpoints and uncertainty

Hallucination (chat)
Contradicting readouts / (wrong + off-topic + consistent). Lower is better. Also inspect assertion share, off-topic rate, empty outputs and stage-2 claim tallies.

Multihop (multi-token)
Questions with all required intermediate entities recovered together in one readout. Higher is better.

Chained intermediates
Questions with a required intermediate number ranked first by the judge at a reading site. Higher is better.

Role-bound association
Questions with the required entity-role bindings recovered at a reading site. Higher is better.

Rate intervals describe uncertainty in one method's overall rate. Paired intervals describe the change on the same grouped questions.
